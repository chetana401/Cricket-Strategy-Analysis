# 🏏 Cricket Strategy Analysis

Cricket Strategy Analysis is a data-driven application designed to analyze cricket match statistics and provide insights into team and player performance.

The system uses historical match data, player statistics, and match situations to identify performance patterns and support strategic decision-making.

## 🚀 Features

* 📊 **Match Analysis** – Analyze historical cricket match data.
* 🏏 **Player Performance Analysis** – Evaluate batting and bowling performance.
* 📈 **Team Performance Analysis** – Compare teams across different matches and conditions.
* 🎯 **Match Situation Analysis** – Analyze performance based on overs, wickets, runs, and required run rate.
* 📉 **Statistical Insights** – Identify trends and performance patterns.
* 🔮 **Prediction Module** – Use machine learning to estimate match-related outcomes based on available historical data.
* 📊 **Data Visualization** – Display important cricket statistics using charts and graphs.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-learn
* **Data Visualization:** Matplotlib, Seaborn
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask
* **Database:** SQLite / MySQL
* **Version Control:** Git & GitHub

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Cricket-Strategy-Analysis.git
```

### 2. Navigate to the project directory

```bash
cd Cricket-Strategy-Analysis
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the local URL displayed in the terminal to access the application.

## 📊 Analysis Parameters

The system can analyze:

### Batting

* Runs
* Strike Rate
* Batting Average
* Boundaries
* Balls Faced
* Runs by Overs

### Bowling

* Wickets
* Economy Rate
* Bowling Average
* Overs
* Runs Conceded
* Dot Balls

### Match Situation

* Current Score
* Wickets Lost
* Overs Completed
* Run Rate
* Required Run Rate
* Target
* Powerplay Performance
* Death Overs Performance

## 🎯 Objective

The objective of this project is to use cricket data and machine learning techniques to understand match patterns, evaluate player and team performance, and generate meaningful strategic insights.

The system converts historical cricket data into visual and statistical information that can be used for match analysis and performance evaluation.
